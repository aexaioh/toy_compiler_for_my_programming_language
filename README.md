# Тесты
Тесты я выложил. 
Чтобы запустить тесты, надо чтобы файлы языка (.myl) и mylangc.py были в 1 директории.
Так же, для компиляции нужен компилятор, который поддерживает C99+ и расширения от GNU.
Чтобы прогнать все тесты разом, надо всего лишь в директории где лежат файлы (.myl) и mylangc.py запустить скрипт `./run_all` (run_all.sh)
